# Calls dataset: sources (WP-05)

`calls.json`: 37 real calls (25 curated on 2026-11-13 + 12 added on 2026-11-14), each checked on its official page or bases on its `verifiedAt` date. Fixture calls (`fixture-*`) are fictional and never appear here.

## Demo calls (used by WP-08 / WP-09)
- **Creator (Galicia, visual arts):** `a-laracha-concurso-fotografia-2026`. Photography contest of the Concello de A Laracha, with real criteria (impacto visual / calidad técnico-artística / creatividad, rescaled 34/33/33), image limits and a no-AI rule. Deadline estimated: 25 natural days from the BOP extract of 10/11/2026 = 5/12/2026 (the bases also mention counting from the web publication, and one passage says 25 working days: confirm at sede.alaracha.gal).
- **Creator (illustration, best criteria for the jury demo):** `calahorra-cartel-jornadas-verdura-2027`. Five weighted criteria (30/25/25/10/10) from the bases, open to anyone in Spain, closes 03/12/2026.
- **Business (Galicia):** `igape-re-acciona-2026`. IGAPE consultancy for autónomos and pymes (80 % paid). It closes **16/11/2026**, so it shows as "cierra en 2 días" on demo day, and **it needs at least 3 workers** (`eligibility.minEmployees: 3`), so a 1-employee autónomo no longer gets it. It is non-competitive, so it has **no scored criteria**: for the jury beat use a creator call, or treat it as a completeness check.
- No Galician digitalisation or crafts call is open in November 2026. Ticket Innova, the autónomo programmes and the Premios de Artesanía are included as `recurring`, with their 2026 data.

- `eligibility.other` holds **only requirements** (shown as "Confírmalo" by matching). Fees and "no cash prize" notes are in `amountText`; "first-come" (no competitiva) is in `summary`.

## How the data was obtained
- **BDNS API** (`https://www.infosubvenciones.es/bdnstrans/api`, public, no key, always `vpd=GE`), verified 2026-11-13:
  - `GET /convocatorias/busqueda?descripcion=…&finalidad=…&regiones=…&fechaDesde=dd/mm/yyyy&page&pageSize`: search. Useful filter ids: finalidad 11 cultura, 14 comercio/turismo/pymes, 6 empleo, 17 I+D+i; regiones 1 España, 3 Galicia.
  - `GET /convocatorias?numConv=<codigoBDNS>`: full record (beneficiaries, NUTS regions, CNAE sectors, budget, dates, documents).
  - `GET /convocatorias/documentos?idDocumento=<id>`: bases PDF.
  - `GET /concesiones/busqueda?numeroConvocatoria=<codigoBDNS>`: past awards. Empty for open calls; not used yet (B3).
  - Rate-limits bursts with **429**: the client retries with backoff.
- **What BDNS lacks:**
  - Criteria, requirements, documents and per-applicant amounts exist only in the bases PDF, so I read every curated call's PDF.
  - Deadlines are often free text; with no API key, they were computed or copied by hand.
  - **BDNS `regiones` is the impact area, not a residence requirement.** Most municipal contests (A Laracha, Calahorra, Cabra…) accept anyone, so `eligibility.residence` follows the bases, not BDNS.
- **Raw records** for the BDNS-sourced calls are in `raw/<codigoBDNS>.json` (offline re-runs).
- **Live ingest:** `npm run calls:ingest` writes `bdns-cache.json` (`source: "bdns"`, structured by `getAi().structureCall`). It keeps the previous cache on any failure. Curated `calls.json` wins on id clashes. Its output is unreviewed: don't use it for the demo without checking it.
- **Live catalogue at runtime** (`src/features/calls-ingest/live.ts`): when a profile is completed or updated (and when its feed loads), the server searches BDNS in the background with queries derived from that profile (disciplines/sector → `descripcion`, comunidad → `regiones`, creator → `finalidad` 11, business → 14, plus 11 for cultural businesses). New calls are structured once and added to the shared catalogue `<MECENA_DATA_DIR>/calls/bdns-live.json` (`/data` on Fly), which holds public call data only; which searches ran for a profile and what they found is kept per profile in `<MECENA_DATA_DIR>/profile-searches.json`. A call already in the catalogue, the seed or `bdns-cache.json` (same BDNS code) is never sent to Claude again. Every day an in-process scheduler (`src/instrumentation.ts`) re-runs the default and the known profiles' searches (capped) and prunes expired calls. It runs when `ANTHROPIC_API_KEY` is set (never caching mock-structured data); `MECENA_CALLS_LIVE=0` turns it off, `=1` forces it on.
- **National sweep for creators** (`npm run calls:sweep`, `src/features/calls-ingest/sweep.ts` + `national-sweep.ts`): the per-profile searches only look at the profile's comunidad and disciplines, so the catalogue stays small. The sweep reads BDNS culture (`finalidad=11`, all comunidades, last 90 days; ~3.800 records) plus term searches (certamen, concurso, premio, beca, cartel, pintura, música, teatro…), and filters in order, each step cheaper than the next: (1) **title**, no network: agreements, nominative/direct grants, already-granted awards, calls for associations, schools, kids, heritage works, fiestas and food contests are dropped; a title must name an artistic practice or be a generic prize/certamen/beca with no other audience; (2) **BDNS detail**: competitive concurrence, open, deadline not expired; (3) **beneficiaries**: a call only for companies, non-profits or administrations is dropped (no beneficiary data = keep); (4) only then Claude structures it, into the same shared `bdns-live.json`, under the usual caps (`--max`, default 50 per run, `MAX_STRUCTURED_PER_DAY`). `--dry-run` runs everything except Claude and the catalogue write, and needs no API key; a real run without `ANTHROPIC_API_KEY` refuses (the mock structurer would fill the catalogue with placeholders). The title lists were tuned on 600 real BDNS culture titles (Aug-Nov 2026): ~7 % passed, versus the ~85 % that were convenios, nominative grants, fiestas or associations.
- **Criteria:** `criteriaSource: "bases"` = points published in the bases, rescaled to 100 (largest remainder). Rescaled from another total: `a-laracha-concurso-fotografia-2026` (30), `getxo-novela-corta-ramiro-pinilla-2027` (10), `icaa-cortometrajes-realizados-2027` (75) and `deputacion-coruna-bolsas-perfeccionamento-artistico-2026` (10, arts area, applicants 23-35). `"estimated"` = the bases list no points (weights split evenly) or the call has none (non-competitive).
- **Recurring calls** (`status: "recurring"`, `deadline: null`): annual programmes whose 2026 edition has closed; amounts and requirements are from the 2026 edition. Their `deadlineText` deliberately contains no date, so the data standard does not read last year's date as this year's deadline.
